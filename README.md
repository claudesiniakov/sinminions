# SinMinions

Компаньон для macOS: зелёный призрак Moth в стиле терминала Fallout живёт поверх рабочего стола — парит, перелетает по экрану, говорит короткие реплики и засыпает, когда вы отходите. Двойной щелчок открывает чат с ИИ и монитор.

Только для Mac с Apple Silicon, macOS 14 и новее.

## Что умеет

- Парит, моргает и следит глазами за курсором.
- Раз в несколько минут перелетает в другую точку экрана и говорит реплику.
- Иногда телепортируется: открывает синий портал под собой, втягивается и выходит из оранжевого в другой точке экрана (отключается в настройках).
- Засыпает после 5 минут без ввода; любое движение мыши или нажатие клавиши будит.
- **Двойной щелчок** — открывает чат. Одиночный — реакция. Перетаскивание — переносит на новое место.
- Щелчки мимо силуэта проходят в окно под ним; фокус ввода не забирается.
- Меню управления — у значка Moth в строке меню: скрыть, усыпить на час, вернуть в угол, обновить, настройки.
- Обновляется сам из GitHub Releases (проверка раз в сутки, установка по вашей команде).

## Чат и команды

Двойной щелчок открывает чат с выбранной моделью. В той же строке можно ввести команду приложения, например `/help` или `/coffee`. Команды работают и без ключа модели. Команда `/shell` открывает zsh, а `exit` возвращает в чат.

## Установка

Скачайте `SinMinions.zip` со страницы [релизов](https://github.com/claudesiniakov/sinminions/releases), распакуйте и перенесите `SinMinions.app` в «Программы». При первом запуске: правый щелчок по приложению → «Открыть».

## Сборка

```sh
swift test
./scripts/build-app.sh   # build/SinMinions.app и build/SinMinions.zip
```

Сборка, тесты и релизы идут в GitHub Actions; релиз публикуется по тегу `vX.Y.Z`.

## Устройство

- `Sources/SinMinionsCore` — логика без интерфейса: автомат поведения, реплики, геометрия, лента обновлений. Покрыта тестами.
- `Sources/SinMinions` — приложение: окно персонажа (AppKit, Core Animation), пузырь, меню, настройки (SwiftUI), обновление.

Персонаж взят из [claudesiniakov/summary](https://github.com/claudesiniakov/summary).
