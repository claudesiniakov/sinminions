# SinMinions

Компаньон для macOS: зелёный призрак Moth в стиле терминала Fallout живёт поверх рабочего стола — парит, перелетает по экрану, говорит короткие реплики и засыпает, когда вы отходите. Двойной щелчок открывает чат с ИИ и монитор.

Только для Mac с Apple Silicon, macOS 14 и новее.

## Что умеет

- Парит, моргает и следит глазами за курсором.
- Раз в несколько минут перелетает в другую точку экрана и говорит реплику.
- Иногда телепортируется: открывает синий портал под собой, втягивается и выходит из оранжевого в другой точке экрана (отключается в настройках).
- Засыпает после 5 минут без ввода; любое движение мыши или нажатие клавиши будит.
- **Двойной щелчок** — открывает чат. Одиночный — реакция. Перетаскивание — переносит на новое место.
- Щелчки мимо силуэта проходят в окно под ним; фокус ввода не забирается.
- Меню управления — у значка Moth в строке меню: скрыть, усыпить на час, вернуть в угол, обновить, настройки.
- Обновляется сам из GitHub Releases (проверка раз в сутки, установка по вашей команде).

## Чат и команды

Двойной щелчок открывает чат с выбранной моделью. В той же строке можно ввести команду приложения, например `/help` или `/coffee`. Команды работают и без ключа модели. Команда `/shell` открывает zsh, а `exit` возвращает в чат.

## Установка

Скачайте `SinMinions.zip` со страницы [релизов](https://github.com/claudesiniakov/sinminions/releases), распакуйте и перенесите `SinMinions.app` в «Программы».

Приложение подписано постоянным самоподписанным сертификатом, но **не нотаризовано** (для нотаризации нужна программа Apple Developer). Поэтому при первом запуске Gatekeeper его не пропускает:

- macOS 15 и новее: попробуйте открыть приложение, затем «Системные настройки» → «Конфиденциальность и безопасность» → кнопка «Всё равно открыть». Обход через правый щелчок → «Открыть» в этих версиях убран.
- macOS 14: правый щелчок по приложению → «Открыть».

Тот же эффект даёт снятие карантина в терминале:

```sh
xattr -dr com.apple.quarantine /Applications/SinMinions.app
```

Подпись не меняется от версии к версии, поэтому выданные разрешения (например, «Универсальный доступ») переживают обновления.

## Сборка

```sh
swift test
./scripts/build-app.sh   # build/SinMinions.app и build/SinMinions.zip
```

Сборка, тесты и релизы идут в GitHub Actions.

## Релиз

1. Убедиться, что `main` зелёный, и поднять версию в теге.
2. Поставить **аннотированный** тег на коммит из `main`: `git tag -a v0.1.35 -m "Что нового"` и запушить тег.
   Сообщение тега становится текстом релиза, поэтому легковесные теги CI отклоняет.
3. CI соберёт и подпишет приложение, прогонит тесты и smoke-снимки, затем отдельный job проверит,
   что тег стоит на `main` и версия в архиве совпадает с тегом, и опубликует релиз.

Право записи в репозиторий есть только у релизного job; сборка работает с `contents: read` и без сохранения токена в `.git/config`.
Ключ подписи живёт в job не больше часа и удаляется из связки ключей сразу после упаковки.

Доверие к обновлению опирается на список отпечатков сертификатов в `Sources/SinMinionsCore/SigningIdentity.swift`.
Если сертификат меняется, сначала выпускается переходная версия с двумя отпечатками: иначе установленные копии отвергнут новый архив.

## Устройство

- `Sources/SinMinionsCore` — логика без интерфейса: автомат поведения, реплики, геометрия, лента обновлений. Покрыта тестами.
- `Sources/SinMinions` — приложение: окно персонажа (AppKit, Core Animation), пузырь, меню, настройки (SwiftUI), обновление.

Персонаж взят из [claudesiniakov/summary](https://github.com/claudesiniakov/summary).
